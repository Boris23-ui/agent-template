# pstack for this project

## Principles
- Earn your features
- Verification first
- No slop
- Keep scope tight
- Prefer evidence over invention

## Check before starting
- What user problem are we solving?
- What is the minimal implementation?
- What are the risks?
- What is out of scope?

## Implement
1. Write tests or validation first
2. Make the smallest viable change
3. Keep the PR reviewable
4. Avoid unrelated cleanup

## Review before shipping
- Typecheck passes
- Tests pass
- No related scope creep
- Backward compatibility preserved
- Security and secrets not exposed
- Build passes
